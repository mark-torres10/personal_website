### [Talk] Silicon Societies: What happens when millions of AI agents use the Internet alongside us?

A talk given to the PyData Chicago community, on multi-agent systems, how well AI agents simulate human behaviors and beliefs, and where things might be headed as we increasingly rely on AI agents to work, shop, call, and interact with others on our behalf.

- [YouTube link](https://www.youtube.com/watch?v=J974ioFjVF0)
- [Event link](https://www.meetup.com/pydatachi/events/315987808/)

### [Talk] Using LLMs for social science (beyond ChatGPT)

A talk given to the Kellogg community, discussing practical tools, tips, and techniques for integrating AI tools into everyday research workflows. Discussed prompt optimizations, human-in-the-loop workflows, and how to use tools like Claude Code and Cursor.

- [Presentation Slides](https://docs.google.com/presentation/d/189VYscba8AbR5PkQg7jU-cuCQItOkuBlAdaOvpBV5sU/edit?usp=sharing)
- [Demo code](https://github.com/METResearchGroup/llm_social_science_demo)
